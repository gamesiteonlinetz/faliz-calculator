# Faliz Calculator

A polished skeuomorphic scientific calculator built with Expo and React Native.

## Features

- Scientific calculator interface with an enlarged, easy-to-read display
- Custom Faliz app artwork
- Credits & Links sheet for the project’s social and community pages
- Android application ID: `com.gamesiteonline.falizcalculator`

## Development

Install dependencies with pnpm, then start the Expo application:

```sh
pnpm install
pnpm dev
```

Run the project checks with:

```sh
pnpm check
pnpm lint
pnpm test
```
